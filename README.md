# Quote Showcase

Высокопроизводительная in-memory витрина цитат на FastAPI.

Сервис принимает большие снимки каталога, хранит записи в памяти и обслуживает пользовательские запросы через ограниченный LRU-кэш с TTL.

Главная задача проекта — эффективная работа при ограниченных ресурсах и высокой конкурентной нагрузке.

## Основные возможности

- FastAPI REST API.
- Потоковый импорт JSON-снимков.
- Хранение записей в виде raw JSON bytes.
- LRU-кэш с ограничением по объёму памяти.
- TTL-кэширование с временем жизни 15 секунд.
- Single Flight для предотвращения повторной загрузки одной записи при конкурентных запросах.
- Статистика попаданий, промахов и загрузок.
- Нагрузочный тестовый сценарий.

## Архитектура

```text
          Import API
              |
              v
       Streaming Parser
              |
              v
       In-memory Catalog
              |
              v
      FastAPI Read Endpoint
              |
        LRU Cache + TTL
              |
       Cache Miss / Lock
              |
              v
       Catalog Lookup
              |
              v
          Response
```

## API

| Method | Endpoint | Description |
|---|---|---|
| GET | `/health` | Health check |
| GET | `/stats` | Статистика сервиса |
| POST | `/import` | Импорт полного снимка |
| PUT | `/catalog/{id}` | Создание или обновление записи |
| DELETE | `/catalog/{id}` | Удаление записи |
| GET | `/quotes/{id}` | Получение цитаты |

## Особенности реализации

### 1. Memory-efficient storage

Каталог хранит сериализованные JSON-записи в виде bytes, сокращая накладные расходы на хранение Python-объектов.

### 2. LRU + TTL Cache

Кэш использует:

- LRU-вытеснение;
- TTL 15 секунд;
- ограничение размера 512 KB;
- подсчёт используемой памяти.

### 3. Single Flight

Для каждого `quote_id` используется отдельный `asyncio.Lock`.

Одновременные запросы одной отсутствующей в кэше записи объединяются в одну операцию получения данных из каталога.

### 4. Streaming Import

Снимок обрабатывается потоково, а не целиком через `json.loads()`.

Это позволяет работать с большими входными данными при ограниченной памяти.

## Запуск

```bash
git clone https://github.com/Bogdan-95/quote-showcase.git
cd quote-showcase

pip install -r requirements.txt

uvicorn main:app --host 127.0.0.1 --port 8000
```

Проверка:

```bash
curl http://localhost:8000/health
curl http://localhost:8000/stats
```

## Нагрузочные проверки

В репозитории находится сценарий `test_load.py`.

Он проверяет TTL, большой импорт данных и работу сервиса при одновременных запросах.

Для запуска:

```bash
pip install httpx psutil
python test_load.py
```

Сначала необходимо запустить сам сервис.

Обратите внимание: это ручные нагрузочные проверки, а не автоматизированный набор unit-тестов.

## Ограничения

- Каталог хранится в памяти процесса.
- Данные теряются после перезапуска.
- Сервис рассчитан на один процесс приложения.
- Полный импорт очищает кэш.
- Для эксплуатации необходимы дополнительные проверки атомарности обновления снимка и конкурентных сценариев.
