Speed Measurer

CLI-утилита для измерения средней скорости загрузки по URL.

  • Считает среднюю скорость по 10 запросам и читает данные блоками по 64 КБ.

03 · Потоковая обработка

Quote Showcase

FastAPI-сервис импорта и выдачи большого каталога цитат.

  • Обрабатывает каталоги размером до 110 МБ построчным потоковым парсером.
  • Кэш ограничен 512 КБ и TTL 15 секунд, используется LRU.
  • Конкурентные операции защищены через asyncio.Lock; доступны API для импорта, цитат и статистики.
